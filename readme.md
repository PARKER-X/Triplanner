# AI Trip Planner

An AI-powered travel planning system using:

- Large Language Models
- Retrieval Systems
- Ranking Models
- Constraint Optimization
- Agent Architecture


## Vision

Build a reliable AI planner that can create realistic,
personalized, and optimized travel itineraries.


## Core Idea

LLM understands user intent.

Search retrieves real-world information.

Optimization creates feasible plans.

Validation ensures correctness.


## Architecture

User
 ↓
Planner Agent
 ↓
Retrieval
 ↓
Ranking
 ↓
Optimization
 ↓
Validation
 ↓
Final Itinerary
