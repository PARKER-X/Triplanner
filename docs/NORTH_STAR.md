# North Star


## Mission

Build an AI planning intelligence that can transform ambiguous human goals into reliable real-world actions.


## Long Term Vision

A user should be able to say:

"I want a relaxing 10 day Japan trip with my family under $4000"

and the system should understand:

- intent
- preferences
- constraints
- tradeoffs

and produce a plan that actually works.


## Core Principle

Language models are not planners.

They are reasoning interfaces.

The real intelligence comes from:

LLM +
Retrieval +
World Model +
Optimization +
Evaluation


## Success Definition

A plan is successful when:

1. It satisfies constraints.
2. It matches user intent.
3. It works in reality.
4. Users trust it.
